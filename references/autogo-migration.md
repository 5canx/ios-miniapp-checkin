# AutoGo 华硕迁移依据（2026-11-19）

来源：awesomeProject1/common/wxinit.go 的 searchMini、pasteToSearchBox、TapText，以及 minicode/asus.go。以源码实际调用为准，不把全部步骤描述成固定坐标。

| 动作 | 原 AutoGo 实现 | 等待 | AutoDam 迁移要求 |
| --- | --- | --- | --- |
| 打开微信 | app.Launch | 3500 ms | 已确认前台时复用会话 |
| 打开搜索 | TapText 搜索；失败才点区域中心 (1154,225) px | 1200 ms | 旧右上角点在当前消息页可能是加号；使用已验证的可见搜索栏点 |
| 小程序分类 | uiacc.TextContains 小程序 → obj.Click | 1200 ms | 没有原固定坐标。当前 MCP 坐标触摸无转场，须核对控件动作与触摸执行差异，不能认定只是 OCR |
| 输入查询 | 找 Editable 框 → 长按1200ms → 全选/粘贴；菜单限区 OCR | 长按后1000ms；全选后600ms；粘贴后800ms；步骤后800ms | 复用剪贴板替换与旧内容清理，不能默认为直接输入完全等价 |
| 提交搜索 | motion.KeyAction(84) 回车 | 2000 ms | 对应 MCP 已有 press_key enter；不是固定点右上角 |
| 打开结果 | 区域中心 (604,603) px，Go 整数除法 | 3000 ms | 折算 (201.333,201) pt；搜索卡动态，需确认目标身份再用 |
| 关闭 | (1197,207) px | 2000 ms | (399,69) pt；保留退出状态确认 |

坐标基准1284×2778像素，当前手机428×926屏幕点、倍率3。AutoGo Sx/Sy 输入基准像素；MCP tap_screen 输入屏幕点，不能直接复制像素值。

当前 minicode/asus.go 的 (1146,2630) 已是上一轮从 AutoDam 迁入的点位，不能再循环引用它作为“旧 AutoGo 独立验证”的证据。原来的我的区域为 (1100,2597)-(1199,2655)，区域中心仅是回退点，不等于每次实际命中的控件坐标。

当前结论：AutoGo 的正常导航没有逐步全屏 OCR，但包含原生控件动作和粘贴菜单 OCR。AutoDam 0.3.6 重跑在分类点击后停止，OCR能返回同一页面；触摸是否生效与微信响应尚未查明。此表是迁移依据，未声称新的完整等价实现已安装或验收。

## 0.3.7 真机调试更新

已实际修改并安装运行器：剪贴板替换、长按1200ms、原等待、回车提交；已知布局不再回退搜索框 AX 查询。82项本地回归通过。一次恢复后分类页已进入，粘贴尚未验收。后续独占运行在OCR前启动确认失败。单独调用launch_app后，实际截图是微信消息列表，而MCP前台仍报AutoDam：确认设备接口前台信息不一致。必须先修复/恢复接口，不删除前台守卫，不继续盲点；不得归因为OCR卡死或标记全流程成功。手机运行二进制已与本次构建逐架构核对，只有RootHide预期签名变更。

## 0.3.12 真机复验

本机 RootHide 的 MCP 偶尔保留退到后台的 AutoDam 编辑器为前台，退出残留界面进程可恢复。微信流程在编辑器点击“立即运行”时，提交已保存的任务后自动退出界面，由守护进程核对真实前台并执行。该交接适用于本机 MCP，外部桥接任务仍需确认设备当前状态。

搜索框使用原机型已确认的 (94,75) pt 长按位置，iOS 粘贴横幅遮挡时可等待后补读一次。旧查询可在确认搜索页面后以 (21,75) pt 返回。真机从“立即运行”提交并完成 7 步。前台确认 0.24 秒，完整粘贴和回车通过，读取已登录个人中心并退出。搜索从已选小程序分类页开始。步骤共 42.36 秒，12 次 OCR 共 26.29 秒。验收为个人中心回执。

## 0.3.18 粘贴容错

iOS 粘贴提示可覆盖顶部查询，菜单首次点击也可能未生效。现在最多五次延迟限区回读，每次间隔两秒。只有明确空框且“粘贴”菜单仍在，才补点一次并再等待六秒。菜单未出现时最多两次局部补查，确认空框时可重新聚焦并长按一次。完整目标名称确认后才提交回车。

真机从 AutoDam 影视飓风原任务完成 16 步，并取得当次“今日已签到”回执。该轮补点一次粘贴后，第三次限区核对成功。手机旧失败候选已改名提醒，原任务已采用验证过的稳定活动步骤。新的 AutoDam 版本仍需按 ActivitySkill 的环境校验流程重新验证候选，不修改旧稳定版的验证证据。

## 0.3.19 默认自动输入

设备 input_text 支持直接向已聚焦搜索框发送文字。微信搜索已改为确认空框后直接输入，局部核对完整名称再回车。明确仍为空框时仅允许重新聚焦补试一次，未知或部分内容不追加。原“全选/粘贴”菜单链已从共享微信搜索实现移除。此变更作用于所有共用导航的小程序。

影视飓风任务在真机完成16步并取得今日已签到回执，输入步骤4.13秒，名称首次核对成功。源代码位于 AutoDam 的 Sources/CNMiniTasks.m 中 enterQuery。手机配置由 bridge-info 返回的 config_path 与已有偏好设置加载，电脑上的实际流程副本由 link.py read 保存到私有 autodam-link/scripts 目录。
