# 业务路径与回执

微信公共入口先完成四个可见导航步骤。然后从当前安装版本的预设及用户实际导出的步骤中复用下表。表中列出用于判页的公开界面语义；本次运行结果、余额、奖励数量、昵称和个人定位均保存在私有记录。

| 目标 / 内置任务 | 路径 | 可接受的业务证据 |
|---|---|---|
| 华硕商城 / `asus` | 核对品牌 → 底栏「我的」→ 个人中心 | 顶部「个人中心」、中部「华硕会员」以及订单或服务栏目共同出现。此原流程的验收范围为进入个人中心；如需签到，另找到实际签到入口和当天回执再增加步骤。 |
| 影视飓风 Club / `storm` | 进个人中心 → 等会员卡加载 → 在右半屏滚动找「日历签到」→ 核对「签到送好礼」→ 读当前状态 | 顶部「今日已签到」，或同一结果弹窗的「签到成功」与奖励提示。未签到才点「立即签到」。连续天数和静态积分规则不能证明当日签到或实际发放数。 |
| 安慕希 / `yogurt` | 首页「每日签到」→ 活动说明 → 滚到「立即参与」→ 核对「集安比拼图碎片」→ 查「每日任务」 | 同一行「每日签到」＋完成进度 `(1/1)`＋「已完成」。未签时点「签到领拼图」，若展示领取弹窗则在确认后领取，再看同一行；按流程要求保存回执后关小程序。说明页示意图及其他任务行不作为回执。 |
| 七彩虹商城 / `colorful` | 个人中心头像旁「签到」→ 查「每日签到」面板 → 回个人中心点「积分」→ 查流水，再决定是否回面板签到 | 以设备当天日期、同一笔记录中的签到标题和正积分验收。已签即结束；向下翻到较早日期才证明今日记录已读完整。无法确定记录日期或归属时暂停。面板积分规则和按钮不能证明入账。 |

## 幂等与归属

签到前读当天稳定状态和可见余额；确认未签才点业务按钮。动作后等待页面稳定，再读取新回执。已签到分支应保留“已完成”状态和读取时间，首签时间、奖励归属不明可写未知。只有动作前后有对应记录时才能写“本次新增”。同日重跑应跳过会发放奖励的动作。

页面只显示规则文案时，记录为“活动规则”；抽奖奖品、拼图、经验值与积分各用各自单位。账户余额的数据类型也要看页面标签，不能拿积分代替现金。采集方式见 [账户与日志](account-data.md)。

## 已有验证范围

RootHide、iOS MCP 1.2.8、autodam 0.2 系列已有四个目标小程序的实机入口证据。三种签到业务各有上述页面或流水回执。华硕、七彩虹与安慕希已有编辑器完整流程通过的记录。影视飓风已有日历及回执证据，完整运行的验证应按安装版最新测试记录确认。更换版本或账号后，复用路径并在当次运行核对业务回执；只有本机保存的本次记录能说明个人奖励与余额。
