# 失败与恢复

| 故障 | 先取证 | 恢复与停止条件 |
|---|---|---|
| 手机／MCP 断线 | 连接通道、最后完成的步骤、是否已有动作送出 | 只读探活，恢复后重新确认宿主及页面；动作可能已送出时先查回执 |
| 黑屏、前台冲突 | 锁屏状态、截图、前台识别、时间戳 | 使用当前运行器支持且用户授权的唤醒；需要口令或安全确认时交用户。前台冲突消除后再输入 |
| 加载间歇、WebView 缺树 | 连续帧或页面文字是否在变化、OCR 区域覆盖 | 有界等待相关锚点稳定；树为空时取当前 OCR。等待上限内未出现锚点就保存现场 |
| 坐标或方向变化 | 逻辑尺寸、像素缩放、方向、按钮区域 | 仅重标定受影响区域并验证其后置页面，更新布局指纹 |
| 新弹窗或陌生账号页 | 弹层主体、选项、遮挡、当前动作 | 依权限表分类。未知、付费或账号验证暂停；由人处理后继续 |
| 点击后结果不明确 | 已送出的动作、前后页面、时间与是否跨日 | 查对应日任务行或流水。若结果仍含糊保留“未确认”，保持现场。避免重放有副作用动作 |
| 误命中“已完成” | 核对控件的行、日期、奖励单位与所在页面 | 要求同页同一行或对应账目，排除静态说明、其他任务或昨天的日志 |

每次修复记录原现象、原因、受影响步骤、具体改动与复测范围。只恢复可判别状态；不断延长超时容易掩盖定位或页面切换错误。
