# 识别页面与指纹

1. 从本次只读采样中读取前台宿主、当前方向、大小和缩放。入口确认后优先复用绑定页面和几何的固定坐标及已验证顺序，不逐步重新抓树/OCR。未知入口或异常才通过页面标题与独立锚点、可用的无障碍树或 OCR 确认。前台查询有缓存时用额外的当前截图确认；两者冲突时停止手势。
2. 用“同一容器/行”“标题下方”“底栏区域”等关系区分同名文字。比如签到规则、广告和实际签到按钮可同时出现。“我的”底栏需宿主身份与小程序身份都成立。记录控件真实可点击范围，不把说明文字误作按钮。
3. 比例框按当前逻辑屏宽高换算：左、上、右、下分别除以宽、高、宽、高。截图像素先转换为当前设备点；记录 scale。无需无差别扩大搜索范围：例如异步会员卡挤动日历入口时，重新取两帧，确认位置稳定后点其文字。
4. 采样指纹用不带数值的稳定标记，如 `profile_heading`、`daily_row_label`。将同页稳定锚点按 ID 归类；将瞬时成功弹窗、今日状态、账户值和设备标识排除出稳定布局指纹，单独用于业务验收。例见 [观察文件](../examples/observation.json)。
5. `reuse.py plan` 比较 runner、iOS、宿主、小程序版本、几何和功能块摘要。小程序未公开版本时可写 `unavailable`，继续核对页面锚点。仅填此次实际见过的页面；`pending_pages` 在正常执行抵达时验证。已见页锚点变化时重新采样这个页面，并复核相邻转移。基线由完整实机回执建立，保留历史版本。测试页面的示例观察不能当作真实基线。
