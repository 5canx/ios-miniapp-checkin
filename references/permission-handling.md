# 权限、协议与账号

先确认弹层来自系统、宿主还是小程序，记录权限类别和当前步骤。仅申请完成当前任务确实需要、且在用户授权范围内的最小权限。已有拒绝状态应保留并解释功能影响。

已实机验证的华硕登录和“上次提供”账户选择见 [登录经验](login-workflow.md)。复用固定顺序，不每次尝试不同登录方式；类似文案不能未经验证就当成同一入口。

- 本地网络用于已选的本地 MCP 连接，可用该任务先前授权的设置。通知、精确定位、通讯录、相机、照片库通常与读取签到回执无关；优先继续无该权限的分支。文件导入优先使用系统文件选择器。
- 剪贴板粘贴是输入方式之一；能直接输入就使用相应能力。如出现读取个人剪贴板的授权，请确认本次内容和用途，避免读取无关内容。
- 到“我的”页分别记录 logged_in、logged_out、unconfirmed。用户在本次或同一任务中已授权登录时，可以处理该范围内已核对的一键登录和已有绑定手机号；无需反复索要同一授权。无授权、请求新的信息范围或选择不明确时保留现场。验证码、双因素认证和账号安全验证由用户完成，恢复后重新读取页面与登录状态。
- 微信连续异常、修复页或重新登录页出现时，停止所有后续微信复跑，明确等待用户恢复。不自动清缓存、注销、退出账号来制造测试条件。
- 付款、购买、充值和订阅均会改变账户，只有新的具体授权才属于任务。与签到无关的购买页面退出前先确认当前层级。
- 日志可写“该步骤请求手机号／用户已处理”，避免存储号码、验证码、Cookie、Token、密码或原始凭据截图。
