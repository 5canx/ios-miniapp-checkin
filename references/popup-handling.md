# 弹窗与右上角关闭

打开页面及任何长等待后，先判断弹层标题、按钮和前后台归属。使用当前层的语义元素，其次用限区 OCR。已实测且在当前几何范围复核过的小图标可用图像匹配或局部坐标兜底。

| 场景 | 判别和动作 | 后置条件 |
|---|---|---|
| 活动／新手说明 | 核对完整标题与“我知道了”“关闭”或可访问图标，只处理明确可关闭的弹层 | 遮罩消失，目标页品牌和入口恢复 |
| 奖励领取 | 确认本任务、奖励归属和领取按钮，点击前检查当天状态；只点一次 | 回到可观察的日任务行或积分流水，读实际回执 |
| 公告／升级 | 能识别“稍后”且可继续当前任务时，选该按钮 | 版本与页面身份仍适用 |
| 登录／隐私／系统授权 | 识别请求主体、权限与理由；按权限文档处理 | 人工恢复后再次确认账号会话和当前页 |
| 右上角关闭 | 判断是页内弹窗关闭、微信胶囊关闭还是导航返回。只有当前任务需要退出且奖励/回执已保存才操作 | 读取新页面身份，确认只退出预期层级 |
| 无文字遮挡或陌生确认框 | 保存打码前的私有现场，标出遮挡范围并等待定位 | 明确动作语义后再从同一步继续 |

重复出现同一弹窗时记录“已点击后的页面”并停止重复点击。避免用连续点击、全屏模糊 OCR 命中或固定右上角坐标处理不同层级。
